B1 · KOOLITUSED · /admin/koolitused

Drag to reorder, click anywhere on a row

• Reordering: a drag handle ⋮⋮ moves a course in one step, with a single server call when it's dropped. The ↑/↓ buttons stay for keyboard and touch users. Today every one-step move is a round trip (appendix 02). • The whole row opens the editor. „Staatus“ shows „Avaldatud“, „Mustand“ or „Avaldamata muudatused“ (from the draft layer, Q1), so she can see at a glance which courses have edits that aren't live yet. • The pills „Kõik / E-õpe / Kontaktõpe“ get counts. Reordering is still only possible in „Kõik“; the handle is hidden in a filtered view, with a hint saying why. • The price column becomes two lines, „Grupp 350 €“ and „Individuaal 450 €“, so it doesn't wrap mid-word.

B2 · MUUDA KOOLITUST · /admin/koolitused/<id> + ?oppetund=

One long page, with a map, one save model and a publish bar

• Section map (obs. 9): a sticky left column lists the cards that exist for this course type, each with a small status: „3“ (count), „RU puudub“ or „Kontrolli“. A tap scrolls to the card. The page is not split into tabs, so a search with Ctrl+F still finds everything. • The draft bar (Q1, B2) sits under the H1: „Avaldamata muudatused: 3“, „Eelvaade ↗“, „Loobu muudatustest“ (ConfirmPanel) and „Avalda muudatused“. An unpublished course has no draft bar, only SaveStatus. • The side column („Avaldamine“, „Koolituse märgis“, card preview) is sticky. Below 1180 px it moves under the header, not to the very bottom (appendix 02). • „Moodulid ja õppetunnid“ / „Programm“ joins the same autosave and draft (B18). It follows the draft „Õppevorm“ immediately. The per-module „Salvesta“ is removed. A programme point is called „punkt“ in its delete text, not „moodul“. • Each list row (Õpiväljundid, Protokolli punktid, Galerii, test questions) gets a drag handle as well as ↑/↓. Removing a row is instant, with UndoBar. • Lesson drawer: name, text and kind autosave. Files upload at once. The kind switch Video → Tekst on a lesson with a video still asks („Video kustutatakse. Jätkan?“ becomes ConfirmPanel words). „Peida“ becomes a two-state switch, „Õpilastele nähtav / Peidetud“. Removing a file shows UndoBar (B5). The drawer header has SaveStatus, and the close guard is the shared one.

B3 · KALENDER · list + drawer ?id=

Edits to booked sessions say who they affect

• The list gets course and city scopes plus the pills „Tulevased / Möödunud“ with counts. The whole row opens the drawer, and the „Kohad“ column shows a small seat bar. • The drawer autosaves. „Salvesta toimumine“ is removed; „Lisa toimumine“ stays as the explicit create. • A booked session (appendix 03): a line at the top says „3 õpilast on registreerunud. Muudatusest neile kirja ei saadeta.“ Changing the date or time shows that line in the warning colour next to the field. • Setting „Tühistatud“ on a booked session opens a ConfirmPanel: „Kas tühistan toimumise? 3 registreeringut jäävad alles; teavita õpilasi ise.“ • Capacity below the confirmed count is refused in the field: „Kinnitatud on 3 — kohti ei saa olla vähem.“ Changing the course is disabled once anyone is booked. • „Kustuta toimumine“ is shown only when there are no registrations. Otherwise the early-refusal text appears in its place (3.3). • „Protokollid“ is the first button in the drawer and goes to that session's protocols.

B4 · SEADED · /admin/seaded

Four save buttons become none

• The page stays a single page (the anchors #ettemaks #tunnistus #arve #lepingud keep working), with the same section map as the course editor. The cards are grouped into five sections: Kontakt, Uudiskiri, Maksmine (Ettemaksu juhised + Arve andmed; their shared bank fields are now edited in one place), Tunnistus, Lepingud ja tingimused (Privaatsus, Õppetingimused, E-koolituse leping, Kontaktkoolituse leping) and Halduse ligipääs. • One SaveStatus covers every card, so the „Tunnistus“, „Arve andmed“ and „Lepingud“ cards are guarded too (parked). • Contract texts use the draft layer: changes are kept as a draft, and „Avalda uus leping“ opens a ConfirmPanel, „Kas avaldan uue e-koolituse lepingu? 7 aktiivset õpilast peavad selle uuesti kinnitama.“ (appendix 11–16). Placeholders are chips that insert at the cursor. • „Järgmine number“ (certificate and invoice) shows what the next number will look like: „Järgmine: MS LAB 2026-93“ / „MSL2026-007“.

B5 · UUDISKIRI · Tellijad | Kirjad

Write, test and send in one column

• „Kampaaniad“ becomes „Kirjad“ (approved). The list sits on the left and the editor on the right, so opening a letter no longer pushes the editor below the list. • The draft autosaves, so the rule „Salvesta muudatused enne saatmist.“ is gone. Sends use the last saved version. • „Saada proov“ is an informed button with the recipient and language: „Saada proov · maria@… · eesti keeles“. The two radio groups become one select. • „Saada kõigile“ opens a ConfirmPanel with the real sendable count (B9). „Peata saatmine“ keeps its ConfirmPanel. • A draft can be deleted: „Kustuta mustand“ with a ConfirmPanel (B17). Sent letters still can't be deleted, and „Kopeeri“ still makes a new draft. • The vague promise „… see läheb välja, kui eelmine on saadetud.“ is replaced by „Eelmine kiri on veel saatmisel. Saada see, kui see on lõppenud.“ (appendix 11–16). • Tellijad: ListToolbar (search an address) with pills „Kinnitatud 14 / Ootab kinnitust 5“. The CSV buttons become „Laadi alla (CSV)“ for the current filter. This is where the overview's subscriber CSV moved.
