A2 · REGISTREERIMISED · list + drawer ?id=

Money first, everything else folded

What changed and why • List: ListToolbar with search (name, e-mail, phone), a course/session scope and status pills with counts (obs. 6). „Laekunud“ shows money received as „0 / 290 €“. „Liik“, „Modelli abi“ and „Konto“ move into the drawer. The whole row opens the drawer. • Drawer order follows Maria's daily inputs (obs. 3): head with contact → Raha with „Lisa laekumine“ → status and note → invoices → folded Leping, Tagasiside and details → „Tühista registreerimine“. • One money path (B4, obs. 4): „Lisa laekumine“ adds a payment. The amount still owed up to 50 % is preselected and a receipt is ticked by default, so one action records the money, confirms the place (with a seat check) and makes the receipt. „Laekunud summa“ is no longer typed over. A wrong entry is undone through the receipt's „Võta tasumine tagasi“. • Status and „Märkus“ autosave. The status pills are a manual override with two choices; cancelling happens only through „Tühista registreerimine“ and its ConfirmPanel (B10). • Invoices: only one „Koosta arve“ button appears, never two (obs. 3). Rarely used invoice actions sit under „Veel ▾“. • The phone drawer shows head, money and status on the first screen. Today it takes three screens.

A3 · PROTOKOLLID · new index + existing screen

Keep what works and add a front door

What changed and why • New index (B8): today's sessions and the last 14 days, with per-session counts. Individual courses are listed below. On a day with exactly one session, the menu goes straight to that session's protocol screen. • The protocol screen (obs. 14) stays as it is: chips, one card, autosave in the corner. Only the words change. The status chip is now SaveStatus; the back link is „← Protokollid“; the per-student send is an informed button („Saada protokoll Eliisele“), still with no second step; „Lukusta ja saada kõik“ becomes „Saada kõigile (2)“ with ConfirmPanel words („Jah, saada 2 protokolli“ / „Katkesta“). There is no separate "lock" step, so the word is dropped. • The conflict notice gets „Taasta minu tekst“, which puts this screen's lost words back into the boxes. Today they have to be copied by hand.

A4 · HINDAMINE · queue, practical work, test review

Approve all in one tap, then send

What changed and why • Tabs „Ootab hindamist“ | „Tunnistused“. The register moves here from a header button (obs. 7). • Practical work (obs. 13): „Kinnita kõik“ marks every point that has no verdict yet; she then switches only the ones that need „Paranda“. The verdict is one segmented control per point and still saves on the tap. A comment box opens automatically for „Paranda“ and is one tap away for „Kinnitatud“. • Photos are 260 px instead of 88 px, and a tap opens the existing PhotoViewer with swipe. On a phone they are full width. • The send is an informed button: „Saada hinnang · 3 kinnitatud“. It needs no second step, because the summary is already on the button. The test review works the same way („Saada · 1 õige, 1 vale“), so both screens match (obs. 5, 13). • Test review: a pressed verdict can be cleared by tapping it again, as on the practical screen. Marks autosave to the server, no longer only to localStorage.

A5 · ÕPILASED · list + drawer ?id=

One list of her courses, with actions on each row

What changed and why • List: ListToolbar (search filters as she types, so the „Otsi“ button is removed). The table stays a table at 1360 px (parked item). The „Koolitusi“ explainer line becomes a tooltip on the column header. „Lisa õpilane“ moves to a header button that opens a small inline form, as an explicit create. • Drawer: e-courses and contact registrations become one list, „Koolitused“, newest first. Maksed, Lepingud, Päringud and Tagasiside become folded rows with counts. • The (mustand) (avatud kuni …) double brackets in the course select become „{course} · mustand · avatud kuni {date}“ (parked).

Every row leads somewhere

A7 · PÄRINGUD · /admin/paringud

Compact cards, done ones folded away

What changed and why • ListToolbar search across every tab. The tab pills keep their counts. „Kontakt“ and „E-õppe huvi“ were one view on the overview and are now one tab, with an „E-õppe huvi“ tag on the card (appendix 01). • Cards go from a 9-line label/value table to a header (name, kind, date), the message, and one line of facts.
